# Historical-format regression inputs

These files exercise earlier mapping formats; they are test inputs, not current
generated bundles or native import instructions. `historical-0.1.0.bundle.json`
lacks the required extension creator. `synthetic-creator-0.2.0.bundle.json`
contains a deliberately synthetic creator and test extension. Neither provides
factual creator provenance. Keep their distinct identifiers when comparing the
formats. See [mapping migration](../../MIGRATION.md) for the 0.2.1 replacement.
