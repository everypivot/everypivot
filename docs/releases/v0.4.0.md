# EveryPivot v0.4.0 Release Notes

Release date: 2026-05-27

v0.4.0 is the bounded OpenCTI/STIX mapping release. It keeps the public
pattern corpus and `pivot-pattern` schema version stable while adding the
first STIX-side adapter mapping slice and tightening public promotion/deferred
metadata hygiene.

## Added

- A bounded `opencti_stix_v0` adapter/query profile for the validated
  `CTI_SAMPLE_IMPHASH_CLUSTER` pattern.
- A synthetic OpenCTI/STIX mapping fixture and deterministic generated STIX
  2.1 bundle for the import-hash mapping slice.
- A top-level `x_everypivot_*` STIX extension-definition schema document for
  generated mapping metadata.
- Profile-suite checks for OpenCTI/STIX bundles, including suppression
  boundaries, forbidden assessment fields, extension-definition/schema drift,
  source/target form agreement, and deterministic generation.
- Release-pack coverage for OpenCTI/STIX profile assets, generated bundles,
  mapping fixtures, schema files, and the STIX generator tool.
- Repository publishing/versioning guidance for public source, tagged release
  ordering, downloadable artifacts, and stable-release tie breaks.

## Changed

- Hardened Neo4j smoke and query-profile generation so Neo4j tooling skips
  non-Neo4j profiles when multiple adapter backends are present.
- Advanced public promotion-cadence metadata through rounds 3 and 4 without
  changing corpus counts.
- Added deferred-lane hazard consistency metadata and reconciled deferred
  reason vocabulary across public deferred patterns.
- Documented bounded STIX mapping simplifications, including temporal/window
  responsibilities and observed-data bundling semantics for the pressure-test
  fixture.
- Clarified `deferred_reason: insufficient_hazards` schema guidance so repaired
  deferred patterns move to their current live blocker.
- Strengthened validation CI with the relation-catalog check and clarified the
  DCO checkbox/workflow regex sync point.
- Expanded local-clutter ignores for maintainer-only working files.
- Documented the incubator `stix2-validator` path for generated STIX bundles.

## Notes

- No corpus expansion: 176 patterns remain published.
- No schema-version change: `pivot-pattern` remains v1.4.
- Pattern YAML remains backend-neutral; OpenCTI/STIX mapping metadata lives
  outside core pattern semantics.
- The generated STIX bundle is a bounded mapping artifact, not a live OpenCTI
  connector and not a production ingestion guarantee.
- Strict `stix2-validator` validation was run during release preparation via a
  temporary OASIS JSON Schema overlay. A committed wrapper for that validator
  path remains follow-up work.
- This release adds no public real-case corpus and no actor, sponsor, victim,
  mission, authorship, ownership, maliciousness, compromise,
  runtime-confidence, or final-assessment claim.
