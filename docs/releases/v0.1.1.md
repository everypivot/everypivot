# EveryPivot v0.1.1 Release Notes

Release date: 2026-05-22

v0.1.1 is a trust-surface update. It does not expand the corpus or change the
`pivot-pattern` schema version.

## Changed

- Changed the pattern corpus and fixtures license from CC BY-SA 4.0 to
  CC BY 4.0.
- Clarified that commercial, SaaS, product, internal, and proprietary
  downstream uses are allowed under the split license model.
- Updated license metadata in the schema, registry index, release manifest,
  site data, and release-pack tooling.
- Rebuilt committed release artifacts so packaged metadata matches the updated
  license posture.

## Added

- `LICENSE-FAQ.md` with plain-English licensing guidance.
- `GOVERNANCE.md` defining maintainer responsibilities, promotion approval,
  schema-change handling, challenge/demotion flow, and relevance-based vendor
  or conflict disclosure.
- `VALIDATION_SEMANTICS.md` defining lifecycle states as editorial registry
  states rather than runtime truth, attribution, maliciousness, confidence, or
  final assessment labels.
- Hybrid DCO guidance in contribution docs and the pull request template.
- A DCO workflow check that accepts either signed commits or explicit DCO
  confirmation in the pull request body.
- REUSE-style license metadata in `.reuse/dep5`.

## Notes

- `validated` continues to mean curated enough to feature publicly. It does not
  mean a runtime match is true, malicious, attributed, high confidence, or
  finally assessed.
- The EveryPivot trademark policy is unchanged: downstream work may accurately
  describe use of EveryPivot material, but may not brand forks, products, or
  competing registries as EveryPivot.
- No alternative commercial license or exception process is introduced in this
  release.
