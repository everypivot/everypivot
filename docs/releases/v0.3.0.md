# EveryPivot v0.3.0 Release Notes

Release date: 2026-05-25

v0.3.0 is the ecosystem-enablement release. It adds the first
backend-neutral adapter/query-profile pilot, public schema-migration doctrine,
and stronger release/relation hygiene without expanding the corpus or changing
the `pivot-pattern` schema version.

## Added

- Public schema-migration and v1.5 doctrine proposals covering semantic
  families, typed facets, blocked-inference objects, companion/inverse
  relationships, source status, semantic boundaries, and justified
  `parent_pattern` use.
- A backend-neutral adapter/query-profile scaffold under `adapters/`, with a
  Neo4j/Cypher pilot profile and generated demo queries.
- Three synthetic Neo4j/Cypher query-profile targets:
  - `OSINT_SSH_HOSTKEY_CLUSTER`, covering outbound target-side suppression.
  - `CTI_EMAIL_ORIGINATING_IP_TO_MESSAGES`, covering inbound traversal shape
    and source-side negative-list clause presence.
  - `CTI_SAMPLE_IMPHASH_CLUSTER`, covering source-side full-block
    suppression.
- Query-profile fixtures and generated-output checks that preserve caveats,
  blocked assertions, expected fixture targets, and forbidden assessment
  boundaries.
- Optional `cypher-shell` smoke tooling for maintainers who want to execute
  the synthetic query-profile fixtures against a disposable Neo4j database.

## Changed

- Generalized query-profile generation and checking so profile targets are
  declared metadata rather than one hardcoded pattern path.
- Documented the licensing boundary for adapter metadata, generated adapter
  queries, and synthetic query-profile fixtures.
- Hardened fixture release hygiene by adding fixture-manifest coverage checks
  and including the previously tracked `invalid_v12_no_assessment` fixture
  case in the manifest and fixture bundle.
- Hardened relation-catalog review by checking default-corpus snapshot-count
  drift and adding warning-only deprecated-vocabulary sections.
- Updated validation workflow action versions and release artifact checks for
  the current public maintenance surface.

## Notes

- No corpus expansion: 176 patterns remain published.
- No schema-version change: `pivot-pattern` remains v1.4.
- Pattern YAML remains backend-neutral; adapter/query-profile metadata lives
  outside core pattern semantics.
- Generated Cypher is a demo adapter artifact, not a production correctness
  guarantee for arbitrary graph models.
- Case-bound and blocked-inference pilots remain internal design-sidecar
  material. This release adds no public real-case corpus, no validated
  promotion from case-bound material, and no actor, sponsor, victim, mission,
  authorship, ownership, maliciousness, compromise, runtime-confidence, or
  final-assessment claim.
