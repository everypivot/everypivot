# EveryPivot v0.1.2 Release Notes

Release date: 2026-05-24

v0.1.2 is a public-site and release-integrity maintenance update. It does not
expand the corpus or change the `pivot-pattern` schema version.

## Changed

- Updated the custom GitHub Pages workflow to Node.js 24-compatible official
  action majors while preserving the existing prepared-`site/` deploy path.
- Added CI checks for generated-data freshness, static Pages-root link safety,
  and homepage release-snapshot agreement.
- Corrected the committed fixture bundle so the published archive includes the
  current walkthrough fixture example.
- Excluded hidden filesystem metadata such as `.DS_Store` from generated
  corpus and fixture bundles.
- Pinned the third-party GitHub release action to an immutable commit.

## Added

- Public GitHub issue forms for bug/site/tooling reports, new pattern
  proposals, validated-pattern challenges, and schema/docs/governance requests.
- Public issue routing that sends sensitive security material to
  `SECURITY.md` rather than public issue threads.

## Notes

- `validated` continues to mean curated enough to feature publicly. It does not
  mean a runtime match is true, malicious, attributed, high confidence, or
  finally assessed.
- This release keeps `v0.1.1` immutable. The changed fixture bundle is
  published as part of `v0.1.2`.
