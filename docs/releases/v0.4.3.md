# EveryPivot v0.4.3 Release Notes

Release date: 2026-06-03

v0.4.3 is a hotfix release that resolves a REUSE 3.3 compliance failure
introduced by v0.4.2's CI gates. v0.4.2 was tagged and the live site
deployed, but the validate workflow failed the REUSE lint step and the
release-asset job was skipped — so v0.4.2 has no downloadable release
pack on the GitHub Releases page. v0.4.3 corrects the REUSE
configuration and re-ships the release assets that v0.4.2 missed.

The pattern corpus, schema, fixtures, and release-pack composition are
unchanged from v0.4.2. Counts remain 21 validated, 76 working_set,
79 deferred (176 total). The `pivot-pattern` schema remains at v1.4.

## Added

- `LICENSES/Apache-2.0.txt` and `LICENSES/CC-BY-4.0.txt`: canonical
  SPDX-named copies of the project's license texts. REUSE 3.3 expects
  license files at these canonical paths; the existing `LICENSE-CODE`
  and `LICENSE-DATA` (same text content, project-friendly names)
  continue to ship alongside.

## Changed

- `.reuse/dep5`: added `.reachable-history-allowlist` to the Apache-2.0
  stanza. The file was introduced in v0.4.2 but inadvertently left
  uncovered by REUSE metadata, which caused the v0.4.2 CI failure.

## Notes

- Corpus count remains 176. Lane counts unchanged at 21 / 76 / 79.
- No `pivot-pattern` schema-version change; remains v1.4.
- No new public real-case material.
- REUSE lint now passes locally (`uvx --from reuse reuse lint`
  reports `Files with copyright information: 300 / 300`, `Files with
  license information: 300 / 300`, `Congratulations! Your project is
  compliant with version 3.3 of the REUSE Specification`).
- The REUSE 3.3 deprecation warning about `.reuse/dep5` → `REUSE.toml`
  migration is informational; this release retains the dep5 format.
  Migration to `REUSE.toml` is tracked as future work.

## Why this release exists

v0.4.2 introduced REUSE lint as a CI gate without an observational
local verification (PyPI was unreachable from the dev host during
release prep). Two issues only visible at CI runtime tripped the
gate:

1. REUSE 3.3 requires `LICENSES/<SPDX>.txt` files alongside (or
   instead of) the project-named `LICENSE-CODE` / `LICENSE-DATA`. The
   v0.4.2 dep5 referenced the project-named files but REUSE 3.3 did
   not pick them up as the canonical license text source.
2. The v0.4.2 commit added `.reachable-history-allowlist` (the
   reachable-history scanner's suppression file) but did not add the
   path to `.reuse/dep5`'s Apache-2.0 stanza, leaving it uncovered.

Both failures were documented as the materialised "Warning" risk in
v0.4.2's release-prep disclosure ("REUSE lint installs from pipx in
CI; not observationally verified locally") rather than discovered as
a surprise.

## Migration notes

Consumers depending on a downloadable `v0.4.2` release pack from
GitHub Releases should use `v0.4.3` instead. The live
`everypivot.io` site already serves the v0.4.2 corpus contents (since
the Pages deploy succeeded for v0.4.2); v0.4.3 updates the live site
metadata to match the v0.4.3 tag, with no underlying corpus change.
