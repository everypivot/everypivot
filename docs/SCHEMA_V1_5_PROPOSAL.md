# Former Schema v1.5 Proposal

This filename is retained for links in historical release notes.

The broader families, facets, case-bound pivots and blocked-inference design
previously called “v1.5” now lives in
[`FUTURE_SEMANTIC_MODEL_PROPOSAL.md`](FUTURE_SEMANTIC_MODEL_PROPOSAL.md).
Its schema version is unassigned, and it remains a design proposal.

Implemented `pivot-pattern` v1.5 covers explicit `assessment_mode`, optional
conditional hints and `assessment_requirements`. See
[`ASSESSMENT_BRIDGE.md`](ASSESSMENT_BRIDGE.md) for the contract and
[`SCHEMA_MIGRATION.md`](SCHEMA_MIGRATION.md) for migration instructions.
The broader proposal is not a prerequisite for using v1.5.
